# 🚀 Chat Interno - Guía Rápida

## ⚡ Inicio Rápido (2 minutos)

### 1. Acceder al Chat

```
Dashboard → Menú Lateral → 💬 Chat Interno
```

### 2. Iniciar Conversación

1. Click en **✏️** (Nueva conversación)
2. Busca un usuario
3. Click en el usuario
4. ¡Escribe tu mensaje!

### 3. Enviar Mensaje

```
Escribe → Enter (o click en "Enviar")
```

## 💡 Funciones Principales

### ✅ Mensajería en Tiempo Real
Los mensajes aparecen sin recargar la página

### 🔍 Búsqueda de Usuarios
Busca por nombre o rol: "Juan", "profesor", "técnico"

### 🔔 Notificaciones
Badge con contador de mensajes no leídos

### 👤 Estado de Usuarios
- ● Verde = En línea
- ● Gris = Desconectado

### 📱 Responsive
Funciona en desktop, tablet y móvil

## 🎯 Casos de Uso

### Profesor → Técnico
```
"Carlos, el proyector de la sala 3 no funciona"
```

### Director → Profesor
```
"Juan, ¿podemos confirmar el horario del evento?"
```

### Administrador → Todos
```
"Recordatorio: Reunión mañana a las 10:00"
```

## 🔧 Atajos de Teclado

| Tecla | Acción |
|-------|--------|
| **Enter** | Enviar mensaje |
| **Ctrl + F** | Buscar usuarios |
| **Esc** | Cerrar modal |

---

## 📊 Características

- ✅ Solo usuarios del mismo colegio
- ✅ Historial de mensajes guardado
- ✅ Indicador de mensajes no leídos
- ✅ Hora y fecha de cada mensaje
- ✅ Avatar con inicial del nombre
- ✅ Rol visible en cada mensaje

---

## 🐛 Problemas Comunes

### No veo usuarios
→ Verifica que estés autenticado

### No se envían mensajes
→ Selecciona una conversación primero

### Badge no se actualiza
→ Recarga la página
