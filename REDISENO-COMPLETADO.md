## 🚀 CÓMO USAR

### Opción 1: Usar las Páginas Nuevas
1. Abrir `dashboard-new.html` en el navegador
2. Navegar a `areas-new.html` para ver áreas
3. Todo funciona con datos demo

### Opción 2: Migrar Páginas Existentes
1. Cambiar CSS: `<link rel="stylesheet" href="css/design-system.css">`
2. Agregar JS: `<script src="js/app.js"></script>`
3. Seguir estructura de `dashboard-new.html`
4. Ver `GUIA-REDISENO-COMPLETO.md` para detalles
