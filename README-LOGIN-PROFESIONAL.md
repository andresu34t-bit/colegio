## 🐛 Troubleshooting

### Logo no se muestra
- Verificar: `images/LOGO EDUGEST.png`
- Fallback automático: emoji 🎓

### Estilos no se aplican
- Limpiar caché: `Ctrl + Shift + R`
- Verificar ruta: `css/login-modern.css`

### Login no funciona
- Verificar credenciales de prueba
- Abrir consola: `F12`
