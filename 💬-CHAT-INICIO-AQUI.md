## 📊 VISTA RÁPIDA DEL SISTEMA

### Interfaz Principal
```
Dashboard → Botón flotante 💬 → Ventana de chat
                                 ├─ Lista de usuarios
                                 ├─ Chat grupal
                                 └─ Conversaciones
```

### Flujo de Usuario
```
1. Usuario abre chat
2. Busca o selecciona destinatario
3. Escribe mensaje
4. Envía (Enter o botón)
5. Destinatario recibe notificación
6. Conversación en tiempo real
```

### Tecnologías
```
Frontend:  HTML5, CSS3, JavaScript ES6+
Backend:   Firebase Realtime Database
UI:        Diseño custom premium
Icons:     SVG inline
Fonts:     Inter (Google Fonts)
```

## 🐛 SOLUCIÓN RÁPIDA DE PROBLEMAS

### El chat no aparece
```
✅ Verifica que los scripts estén incluidos
✅ Revisa la consola del navegador (F12)
✅ Confirma que Firebase esté configurado
```

### No veo usuarios
```
✅ Verifica que tengas el mismo schoolId
✅ Confirma datos en localStorage
✅ Revisa las reglas de Firebase
```

### Los mensajes no se envían
```
✅ Verifica conexión a internet
✅ Revisa permisos de Firebase
✅ Confirma que el usuario esté autenticado
```
