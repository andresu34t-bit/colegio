💬 Chat en Tiempo Real - Demo

Prueba la interfaz del chat sin necesidad de configurar Firebase

📋 Instrucciones

  • Configura dos usuarios diferentes (uno en cada columna)
  • Ambos usuarios deben tener el mismo Colegio
  • Click en "Activar Chat" para cada usuario
  • Usa el botón flotante (esquina inferior derecha) para abrir el chat
  • ¡Envía mensajes entre los usuarios!
