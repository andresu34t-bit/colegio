## ✨ Efectos Visuales

### Hover Effects
```css
transform: translateY(-4px);
box-shadow: 0 12px 24px rgba(0, 0, 0, 0.1);
```

### Focus States
```css
border-color: var(--primary);
box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.1);
```

### Transitions
```css
transition: all 0.3s ease;
```

### Animations
```css
@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
}
```
