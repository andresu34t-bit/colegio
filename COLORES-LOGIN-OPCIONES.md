## 🔧 Cómo Cambiar el Color

Edita el archivo `css/login-modern.css` y busca:

```css
.login-brand-panel {
    background: linear-gradient(135deg, #0f2027 0%, #203a43 50%, #2c5364 100%);
    ...
}
```

Reemplaza con cualquiera de las opciones de arriba.
