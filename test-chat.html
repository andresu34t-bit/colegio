📋 Instrucciones de Prueba

  1. Configura un usuario de prueba usando el formulario de arriba
  2. Haz clic en "Guardar y Activar Chat"
  3. El botón flotante del chat aparecerá en la esquina inferior derecha
  4. Abre esta página en otra pestaña o navegador
  5. Configura un usuario diferente con el mismo "ID de Colegio"
  6. Ahora podrás ver ambos usuarios en la lista y chatear entre ellos
  7. Prueba el chat privado y el chat grupal

⚠️ Importante: Asegúrate de haber configurado Firebase Realtime Database correctamente. Consulta el archivo CHAT-SETUP.md para instrucciones detalladas.
