# 📁 Carpeta de Imágenes - EduGest PME

## 🎨 Logo Principal

Por favor, coloca el logo de EduGest PME en esta carpeta con el nombre:

**`logo-edugest.png`**

### Especificaciones Recomendadas:
- Formato: PNG con fondo transparente
- Tamaño recomendado: 200x200px o 300x300px
- Peso máximo: 100KB

### Ubicación del Logo en la Aplicación:
El logo se mostrará en:
- ✅ Página de login (index.html)
- ✅ Página de registro (registro.html)
- ✅ Sidebar de todas las páginas internas
- ✅ Encabezado del dashboard

### Instrucciones:
1. Guarda la imagen del logo como `logo-edugest.png` en esta carpeta
2. El sistema automáticamente lo mostrará en todas las páginas
3. Si el logo no se muestra, verifica que el nombre del archivo sea exacto

### Alternativa:
Si prefieres usar otro formato o nombre, actualiza las referencias en:
- `index.html`
- `registro.html`
- `dashboard.html` (y otras páginas con sidebar)
