## 🔧 MIGRAR OTRAS PÁGINAS

### Paso 1: Cambiar el CSS
```html
<!-- Reemplazar -->
<link rel="stylesheet" href="css/style.css">

<!-- Por -->
<link rel="stylesheet" href="css/design-system.css">
```

### Paso 2: Agregar JavaScript
```html
<script src="js/app.js"></script>
```

### Paso 3: Copiar Sidebar
Copiar el sidebar de `dashboard.html` que incluye:
- Logo de EDUGEST
- Información del usuario
- Navegación
- Botón de cerrar sesión

### Paso 4: Usar Componentes
Consultar `componentes-demo.html` para ver ejemplos de:
- Botones
- Cards
- Forms
- Tables

## 💡 TIPS RÁPIDOS

### Cambiar Colores
Editar en `css/design-system.css`:
```css
--curriculum-500: #3b82f6;    /* Azul */
--liderazgo-500: #a855f7;     /* Morado */
--convivencia-500: #22c55e;   /* Verde */
```

### Cambiar Tamaño del Logo
Editar en `css/design-system.css`:
```css
.sidebar-logo-img {
    max-width: 100px;  /* Cambiar aquí */
    max-height: 100px; /* Cambiar aquí */
}
```

### Agregar Nuevo Componente
1. Ver ejemplos en `componentes-demo.html`
2. Copiar el código HTML
3. Pegar en tu página
4. Ajustar contenido
